# AWS Cloud based VR setup

## nVidia driver 3D settings
Ambient occlusion - Performance
Anisotropic Filtering - off
Antialiasing settings
	- FXAA - ON
	- Antialiasing setting - OFF (built into most modern games)
	- Gamma Correction - ON
	- Mode: Application Controlled
	- Transparency - Multisampling

Background Application Max Frame Rate - Set it to 30
CUDA settings - ignore
Dynamic Super Resolution (DSR - Factors): OFF
Low Latency - optional for flight sims, but required for shooters - ON
Max Framerate - Uncapped / Unlimited
Multi-Frame Sampled AA (MFAA) - OFF
The Monitor Technology - G-Sync for casual games, Fixed Refresh Rate for competitive ones
OpenGL Rendering GPU  - probably 8
Power management mode - Prefer max performance OR adaptive
Shader Cache Size - default or 10 Gigs
Texture Filtering – Anisotropic Sample Optimization. - ON
Texture Filtering – Negative LOD Bias. - Allow
Texture Filtering – Quality. - High Quality
Texture Filtering – Trilinear Optimization. - ON
Threaded Optimization - Auto
Vertical Sync (Vsync) - Off
Tripple Buffering - Off

Virtual Reality games  - May improve performance at the cost of Increased latency
